# Java Static Web Logging-Project
This is a logging project  was is created to understand the following concepts:
-Core Java 
-JDBC API (Connect the application to the Rational database)
-Servlets (HTTP REQUEST / RESPONSE: GET, POST, DELETE) and generate the response back to the client.
-Filters (Authenticate all user access to the project dashboard).
-HTML (Pages designing / Skeleton).
-CSS (Styling all the static HTML pages using components).
-Tomcat (Java web container that receives all the HTTP REQUESTS from the clients).
-MySQL database (Permanently stores all the data from the user for future use to be retrieved).
-import org.mindrot.jbcrypt.BCrypt: Password hashing important for security and generates hashed password from the database.
-DAO (database layer that speaks to the relational database and execute SQL QUERIES).
